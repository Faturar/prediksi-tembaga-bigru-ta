You are working inside my EXISTING undergraduate thesis repository:

The current system is primarily an admin/internal research application.

I now want to extend it so that the system has TWO usage sides:

1. **Admin side**

   * remains protected by login;
   * manages dataset;
   * imports CSV;
   * trains BiGRU;
   * manages model versions;
   * activates model;
   * views full evaluation;

2. **Public/User side**

   * can view the active model prediction;
   * can choose forecast horizon 1–7 trading periods;
   * can see P+1 through P+N results;
   * can view historical + forecast charts;
   * can view a limited summary of model performance.

`30 historical observations -> one BiGRU output`

→ `Bidirectional GRU 64`
→ `Dropout 0.2`
→ `Dense(1)`

For horizon > 1:

use existing recursive multi-step forecasting implementation.

Example:

30 historical observations → prediction

P+2:
29 historical observations + P+1 → prediction

Do NOT refit scaler.
